(c) How was the key determined — decisive check: is it a small polynomial after inverse NTT
    inverse NTT self-check: round trip of 20 CBD(eta=2) polynomials all match ✓
    sk is split into 1 polynomial (256 coefficients each) and each is inverse-transformed
    If it were a real Kyber-768 secret key, **all** coefficients would have to be in {-2..2} (CBD eta=2).
    Measured as a control: uniform random mod q and the arithmetic pattern both put 254
    of 256 coefficients outside that range — the verdict separates cleanly.
     poly  coefficients     min     max   |c|>2     verdict
    ----------------------------------------------------------
        0         0~255   -1652    1632     256    **not small**

    -> The inverse transform is not small. **It is not a Kyber secret key sampled from CBD.**
       It is not keygen output but values filled by a formula or pattern, or arbitrary values.
       **This means the recovery target is not a real Kyber key, and the attack
       difficulty (candidate distribution, HW distribution) may differ from reality, so the paper
       must state which key was used.**
       Which of these it is requires looking at the relevant line of the collection code (below).
